# Monster12138 Familiar

## How do I install these formulae?

`brew install monster12138/familiar/<formula>`

Or `brew tap monster12138/familiar` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "monster12138/familiar"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
